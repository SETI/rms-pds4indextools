Developer Guide
===============

The Developer Guide is the technical reference for ``rms-pds4indextools``.
It covers installing the package, the configuration-file format, worked
examples, the command-line exit-code contract, the internal architecture,
the API reference, and how to contribute.

Getting started, the step-by-step tutorial, and the complete
command-and-option reference live in the User Guide and are not repeated
here; this guide builds on them. If you are an archivist or data producer
looking for a task-oriented, plain-language walkthrough, start with the
:doc:`/user/index` instead.
