Developer Guide
===============

The Developer Guide is the technical reference for ``rms-pds4indextools``.
It covers installing the package, a quickstart walkthrough, the full
command-line interface, the configuration-file format, worked examples, the
internal architecture, the API reference, and how to contribute.

If you are an archivist or data producer looking for a task-oriented,
plain-language walkthrough, start with the :doc:`/user/index` instead.
