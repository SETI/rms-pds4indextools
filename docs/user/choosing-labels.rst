Choosing which labels to include
================================

You tell the tool where your bundle lives with a bundle root, and which
labels inside it to read with one or more glob patterns such as
``**/*.xml``. This page explains how the bundle root and the patterns work
together to select exactly the labels you want, how to widen or narrow the
selection, and how to include labels whose names end in either ``.xml`` or
``.lblx``.
