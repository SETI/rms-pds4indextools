When things go wrong
====================

Sometimes a run stops with a message instead of an index. This page collects
the most common problems, such as a bundle root that cannot be found, a
pattern that matches no labels, a settings file with a typo, or a schema that
cannot be reached, and explains in plain language what each one means and how
to fix it. It also describes the option that lets a run keep going and report
every problem at once.
