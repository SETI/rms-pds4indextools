Writing your settings file
==========================

The settings file is a small text file, written in YAML, that records your
choices so you do not have to retype them every run. It lists your columns,
controls how the table is written, and describes the index product. This page
walks through the settings file one section at a time, in plain language, so
you can write and edit one confidently even if you have never worked with YAML
before.
