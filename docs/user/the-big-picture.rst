The big picture: from a bundle to an index
==========================================

Building an index has just a few moving parts: a folder of labels called the
bundle, a settings file that says which columns you want, and the two output
files the tool writes. This page gives you the mental model for how those
pieces fit together, so that the more detailed pages that follow make sense.
Once you can picture the flow from a bundle to a finished ``index.csv``, every
later step is a small, concrete task.
