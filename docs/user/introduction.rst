What this tool does for you
===========================

This tool reads a collection of PDS4 labels and gathers the values you care
about into a single table, saved as a comma-separated ``index.csv`` file with
a matching PDS4 label that describes it. Instead of opening each label by hand
to find a title, an identifier, or an observation date, you describe the
columns you want once, run one command, and get a tidy index of your whole
bundle. This page introduces what the tool produces and who it is for.
